2 · Authentication Flow

✅ Successful Login

1
User submits email + password from login form
2
POST /api/v1/auth/login → AuthController
3
Spring AuthenticationManager verifies credentials against DB
4
failedLogins reset to 0 in DB
✓
JWT token generated with role claim → returned to frontend
✓
Frontend stores token, redirects to Dashboard

❌ Failed Login

1
Wrong credentials → BadCredentialsException
2
failedLogins++ saved in DB
!
If failedLogins ≥ 5, account locked for 30 minutes
✗
401 Unauthorized returned

📝 Registration

1
POST /api/v1/auth/register with name, email, password, role
2
Check if email already exists → 400 if duplicate
3
Resolve or auto-create Role (ADMIN / MANAGER / EMPLOYEE)
✓
Password BCrypt hashed, User saved → 201 Created
3 · Expense Lifecycle — Submission to ERP Sync
1
👤
Employee Submits
POST /api/v1/expenses with amount, vendor, receipt, category
2
💱
Currency Conversion
Amount converted to USD via live FX rates
3
💾
Saved as PENDING
Expense record created in DB with status = PENDING
4
📋
Policy Engine
6 rules evaluated: amount, cap, receipt, duplicate, weekend, budget
5
🔔
Notification Sent
Employee notified of submission; Manager alerted if flagged
6
👔
Manager Reviews
POST /expenses/{id}/approve or /reject with remarks
7
🔗
ERP Sync
Approved expense synced to QuickBooks / SAP Concur
✅ CLEAN
All policy rules passed. Expense proceeds to manager review normally.
⚠️ FLAGGED
One or more rules triggered a warning. Manager must manually review the violation.
🚫 AUTO-REJECTED
A critical rule triggered AUTO_REJECT action. Expense status set to REJECTED immediately.
4 · Policy Engine — Rule Types
💰
AMOUNT_LIMIT
Expense USD amount exceeds the configured threshold for the rule.
AUTO_REJECT possible
📅
DAILY_CAP
User has already spent more than the daily cap when this expense is added.
AUTO_REJECT possible
🧾
RECEIPT_REQUIRED
Amount exceeds limit but no receipt URL was attached. Receipt is mandatory.
AUTO_REJECT possible
🔁
DUPLICATE_DETECTION
Same vendor + same amount already submitted within a configurable time window (default 7 days).
FLAGGED
📆
WEEKEND_BLOCK
Expense date falls on a Saturday or Sunday — unusual business activity.
FLAGGED
📊
CATEGORY_BUDGET
Department + category monthly spending would exceed the category's default limit.
FLAGGED
5 · Role-Based Access Control
👤 EMPLOYEE
  • Submit new expense
  • View own expenses
  • View notifications
  • Mark notification read
👔 MANAGER
  • All Employee permissions
  • Approve / Reject expenses
  • View all expenses
  • View pending queue
  • Trigger ERP sync
  • View analytics dashboard
🔴 ADMIN
  • All Manager permissions
  • Toggle policy rules on/off
  • Connect / disconnect ERP integrations
  • Force refresh FX rates
  • View ERP sync logs
🔎 AUDITOR
  • Full audit trail (last 100)
  • Entity-level audit lookup
  • ISO 27001 compliance score
  • PCI DSS compliance score
  • Analytics read access
